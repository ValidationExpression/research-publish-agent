# Research Publish 现代研究工作台设计

## 目标

在不改变现有“研究 → 审阅 → 发布”业务流程和后端接口的前提下，重做 Electron 桌面端的 UI、信息架构与交互反馈。新版采用用户确认的现代浅色编辑工作台方向，解决当前界面留白失衡、对比度偏低、主操作不突出、过程反馈偏技术化的问题。

## 设计原则

- 研究输入是首页唯一的首要任务，视觉焦点必须明确。
- 三步流程始终可见，并明确区分当前、已完成和不可用状态。
- 只展示真实、可操作的能力；不加入后端尚不支持的附件、历史记录或研究参数。
- 保持桌面应用的紧凑度和稳定性，避免营销页式大留白与通用仪表盘式卡片堆叠。
- 所有异步操作都有进行中、成功、失败和恢复反馈。

## 视觉系统

### 色彩

- 应用画布：暖白 `#FBFAF7`
- 导航区域：浅石灰 `#F1F0EC`
- 表面：白色 `#FFFFFF`
- 主文字：石墨黑 `#17191C`
- 次级文字：`#6F7580`
- 边框：`#E4E2DC`
- 主色：钴蓝 `#315CF5`
- 主色浅底：`#EEF2FF`
- 成功：`#1F9D6A`
- 警告：`#C77A16`
- 错误：`#C8473B`

主色用于当前步骤、焦点、链接和主操作。状态色只用于语义反馈，不承担品牌表达。

### 字体与形态

- 使用适合中文的现代无衬线系统字体栈。
- 页面标题 36–42px，正文 14–16px，辅助标签 11–12px。
- 间距遵循 8px 基准网格。
- 常规圆角 8px，输入组合区 10px，状态标签 6px。
- 默认使用细边框和轻微阴影，不使用纸张纹理、玻璃拟态、渐变或装饰性插画。
- 图标统一使用 1.5px 描边的线性 SVG。

## 应用框架

### 标题栏

保留 Electron 自定义标题栏和窗口拖拽区域。左侧显示简化品牌标识与产品名，右侧由系统窗口按钮占位。标题栏与内容区使用细分隔线连接。

### 侧栏

桌面宽度下使用约 250px 的固定侧栏，包含：

1. 品牌标识、`Research Publish` 和副标题“研究 · 审阅 · 发布”。
2. 垂直三步流程：研究、审阅、发布。
3. 底部服务状态：研究服务与 Cookie 插件。

步骤之间由细线连接。当前步骤使用钴蓝侧边线、节点和浅色背景；完成步骤显示完成标记；不可用步骤保持可读，但禁用交互并通过说明文本表达前置条件。

窄窗口下，侧栏转换为顶部横向步骤导航，服务状态进入紧凑状态行。

## 页面设计

### 研究页

页面标题为“今天想研究什么？”，说明研究服务会联网检索并生成可编辑的 Markdown 报告。

核心区域是一个宽幅研究输入组合框：

- 使用多行输入，允许更完整地描述研究主题。
- 保留表单提交语义，支持 `Ctrl/Cmd + Enter` 提交。
- 右侧集成方形箭头主按钮，空内容或运行中时禁用。
- 提供三个可点击的示例主题，点击后只填入输入框，不自动提交。
- 显示字符计数和快捷键提示。

研究开始后，输入区锁定并显示：

- 明确的“研究进行中”状态。
- 将已有 SSE 日志转换为清晰的进度条目，同时保留错误原文供排查。
- 自动滚动到最新消息。
- 完成后沿用现有逻辑进入审阅页。

输入区下方使用横向流程说明展示“联网检索 → 资料分析 → 生成报告”。该区域只解释真实流程，不显示伪造的最近研究数据。

### 审阅页

页面顶部集中展示标题、正文字符数以及“进入发布”主操作。

主体采用双栏：

- 左栏是标题和 Markdown 正文编辑器。
- 右栏是实时渲染预览。
- 两栏拥有独立滚动区域，减少整页跳动。
- 空标题或空正文时，主操作禁用并在相邻位置说明原因。

当窗口不足以支持双栏时，编辑器与预览改为单栏纵向排列。

### 发布页

页面顶部显示当前文章标题、可用平台数、已登录数和已选数。

平台区域使用紧凑列表而非大卡片网格：

- 每行包含选择框、平台名称和登录状态。
- 已登录平台优先排序。
- 未登录平台可见但不能被选择，并提示先在浏览器登录。
- 提供刷新登录状态的次要操作。

发布按钮在无选择或发布中时禁用。发布过程中显示加载状态；完成后就地展示每个平台的成功、失败、链接或错误原因。

## 状态与错误处理

- 服务状态刷新失败时保留上一次已知状态，避免无意义闪烁。
- 研究启动失败、SSE 中断、轮询超时均在研究区就近显示。
- 平台加载失败显示带重试操作的空状态。
- 发布请求失败与轮询超时显示明确错误，不将失败呈现为普通辅助文字。
- 所有动态状态使用 `aria-live` 或等价语义，键盘焦点始终可见。

## 组件边界

- `App`：流程状态、文章数据、服务状态和页面切换。
- `WorkflowSidebar`：品牌、步骤状态和服务状态，只通过属性接收数据。
- `PageHeader`：统一页标题、步骤上下文和页级操作。
- `ResearchComposer`：主题输入、快捷键、提交与运行状态。
- `ResearchProgress`：研究事件与错误反馈。
- `ReviewPage`：编辑数据与预览布局。
- `PublishPage`：平台加载、选择、发布和结果反馈。
- `Icons`：无外部资源依赖的统一线性 SVG 图标。

本次只做与重设计直接相关的组件拆分，不重构后端或同步领域代码。

## 验证标准

- `pnpm --filter @research-publish-agent/desktop typecheck` 通过。
- `pnpm --filter @research-publish-agent/desktop build` 通过。
- 在开发预览中验证研究、审阅、发布三页以及研究运行、平台空状态、发布结果状态。
- 以约 1600×1000、1280×800 和窄窗口尺寸检查布局，不出现横向溢出或关键操作遮挡。
- 验证键盘导航、焦点样式、表单标签、禁用状态和降低动态效果设置。

## 非目标

- 不改变研究或发布 API。
- 不增加研究历史持久化。
- 不增加附件上传、研究深度、来源范围或输出格式设置。
- 不新增登录系统、用户头像或账户菜单。
- 不引入外部图标库、字体下载或图片素材。
